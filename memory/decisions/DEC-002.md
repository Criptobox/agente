## Decisión
Todo se sirve estático desde GitHub Pages. El desarrollo es solo desde móvil,
por la web de GitHub, en 3G. La lógica "de servidor" se hace en GitHub Actions.

## Consecuencia
No hay dónde esconder secretos en el cliente. Rendimiento agresivo obligatorio.
Cualquier build (minificar, bundle CSS) corre en Actions, no local.
