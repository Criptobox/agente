## Problema
Un Personal Access Token de GitHub viajaba por Firebase (lectura pública),
quedando expuesto a cualquiera con acceso a la base.

## Causa raíz
Se guardó/transmitió un secreto por un canal legible desde el cliente.
En hosting estático NO hay lugar seguro en el cliente para un secreto de escritura.

## Solución
Sacar el PAT del cliente y de Firebase. Las operaciones que necesitan token
se hacen desde GitHub Actions (con el GITHUB_TOKEN del runner), no desde el navegador.
Rotar el token filtrado inmediatamente.

## Regla derivada
Ver LESSON-203: ningún secreto vive en el cliente ni viaja por Firebase.
