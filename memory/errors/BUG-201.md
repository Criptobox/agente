## Problema
Se podía entrar al panel admin pulsando Escape: el modal/login se cerraba pero
la vista protegida quedaba accesible detrás. Autenticación saltada por completo.

## Causa raíz
Cerrar el modal (Escape) no equivale a autenticarse. El estado "logueado" se
inferían de la UI (modal abierto/cerrado) en vez de un flag de sesión real.

## Solución
La vista protegida no se renderiza/activa hasta que existe un estado de sesión
verificado. Escape no cambia ese estado. Nunca inferir permiso desde el DOM.

## Regla derivada
Ver LESSON-201: el permiso es estado, no apariencia de UI.
