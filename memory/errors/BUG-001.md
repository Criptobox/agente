## Problema
calculateTotal() devuelve NaN cuando un producto se elimina del carrito.

## Causa raíz
removeItem() borra el objeto pero deja el id en el array de líneas.
calculateTotal() hace price*qty sobre undefined.

## Intento 1 — FALLÓ
Number(x)||0. Oculta el síntoma, el total queda menor al real.
Aprendizaje: no es de tipo, es de integridad referencial.

## Intento 2 — FUNCIONÓ
Filtrar líneas huérfanas antes de reducir + limpiar el array en removeItem().
